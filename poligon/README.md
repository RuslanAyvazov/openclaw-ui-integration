# B2CSQL Studio

Веб-приложение для сборки витрин данных из S2T и SQL-прототипов. В состав входят
Django, PostgreSQL, OpenClaw и интерфейс на React.

## Что загрузить ИИ-ассистенту

Для сборки витрины нужны:

- **S2T (`source-to-target`)** — Excel-файл с описанием целевых схем, таблиц,
  полей, типов, ключей и партиций. Для демонстрации используйте
  [`s2t.xlsx`](s2t.xlsx). Для реальной витрины S2T предоставляет архитектор данных
  или аналитик, который проектировал целевую модель.
- **SQL-прототипы** — готовые запросы `SELECT`, которые получают данные из
  источников и возвращают поля для загрузки витрины. Демонстрационные примеры
  находятся в [`sql_prototypes`](sql_prototypes): для Iceberg нужен
  `DML_inc.sql` и `DML_arc.sql` на каждую таблицу, для Parquet — один
  `DML_inc.sql` на таблицу. Для реальной витрины эти запросы предоставляет
  разработчик или инженер данных, отвечающий за логику получения данных.

В ИИ-ассистент необходимо одновременно загрузить S2T, выбрать Iceberg или
Parquet и приложить соответствующий комплект SQL-прототипов.

Ассистент поддерживает три сценария:

1. для новой витрины кнопка «Проверить и собрать» запускает создание с нуля;
2. команда «добавь поток» с вложениями добавляет отсутствующие таблицы в новую
   ветку `openclaw/update-*`;
3. команда «обнови» с новым составом S2T пересобирает потоки, в которых появились
   дополнительные атрибуты.

Для сценариев 2–3 агент сначала спрашивает пространство и название витрины.
Исходная ветка `main` не изменяется.

## Запуск

```bash
git clone https://github.com/RuslanAyvazov/openclaw-ui-integration.git
cd openclaw-ui-integration/poligon
cp .env.example .env
docker compose up --build -d
```
