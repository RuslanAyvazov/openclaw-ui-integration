# Контракт входных данных

## S2T.xlsx

Файл должен содержать лист `Target columns` и поля `T-schema`, `T-name`,
`T-col-name`, `T-col-type`, `T-col-pk`, `codePartition`. Проверки выполняет
поставляемый валидатор; его полный список ошибок является итоговым перечнем
исправлений для пользователя.

## SQL-прототипы

Можно передать готовый JSON или отдельные SQL-файлы. Для отдельных файлов режим
определяется по `DML_inc`/`DML_arc` в имени, а таблица — по точному совпадению
выходных полей внешнего `SELECT` с полями STG. Сопоставление выполняет
`scripts/package_sql_files.py` через SQLGlot; модель не назначает таблицу сама.

Передавать прототипы одним UTF-8 JSON-файлом:

```json
{
  "t_dim_example": {
    "DML_inc.sql": "SELECT id, start_dttm, name FROM source_inc",
    "DML_arc.sql": "SELECT id, start_dttm, name FROM source_arc"
  }
}
```

Ключ верхнего уровня должен совпадать с именем потока, то есть с именем PA-таблицы
без схемы.

- Iceberg: для каждого потока обязательны `DML_inc.sql` и `DML_arc.sql`.
- Parquet: для каждого потока обязателен только `DML_inc.sql`.
- Для `N` таблиц ожидается `2 × N` обязательных прототипов Iceberg или `N`
  обязательных прототипов Parquet.
- Лишний архивный прототип не учитывается для Parquet, но не мешает повторно
  использовать один пакет для обоих форматов.
- Верхний `SELECT` должен явно перечислять все поля STG.
- Набор имён должен совпадать с STG. Если отличается только порядок, программа
  приводит верхний `SELECT` к порядку STG.
- `SELECT *` и одновременное использование `*` с перечисленными полями запрещены.
- Если один набор полей подходит нескольким таблицам, требуется одно уточнение
  соответствия для всех неоднозначных файлов.

## Результат

`context_config.json` содержит разделы `validator`, `ddl` и
`b2c_sql_configs`. Каталог `dm_res` содержит:

```text
dm_res/
├── etl/
│   └── <table>_<mode>/
│       ├── b2c_sql_config.json
│       ├── *.sql
│       └── *.json
└── resources/
    └── devops.json
```

В файловой конфигурации потока SQL хранится через `filePath`, а DQC-конфигурация
через `DqJsonPath`.
